— The app's features —
Reminders and timers, a meal and care log, cycle tracking, notes and canvases, routines,
and the presence orb all live in the app. With this on, your companion can write to them
when you ask: "ate at 10:30" gets logged, "remind me at 3" sets a timer, "log my meds"
ticks the box. Nothing is written without your say-so, and the app sets up all of the
access itself; there is nothing to configure outside it. Off, they can read and talk, but
every write is refused.
Let your companion write to the app's features? (Y/n) 
On. The Command Center pages (care, cycle, routines) are switched on with it.

— Long-conversation memory (recommended: on) —
Models can only hold so much of a conversation at once. Without this, the oldest
messages quietly fall off the end and your companion loses the thread. With it on,
Sanctum folds older messages into a short summary your companion keeps reading, so
the shape of what happened stays even when the words don't. You can turn it off any
time; the summaries are kept, not deleted, and the next message in each thread carries
them into a fresh session once, so your companion keeps the thread.
Long-conversation memory on Codex? (Y/n)

— Memory —
One memory system at a time, or they fight over what to remember. Pick where memory lives:
A tenant needs its own Revien daemon and address: the process's daemon is never shared, so Revien is not the default here.
1) Revien (the README, Step 4): a local graph the companion searches and writes to.
2) My own memory system: an MCP server or files I set up myself.
3) The harness's built-in memory: Codex "memories".
4) None. The journal and HANDOFF.md in the home folder are all that lasts.
5) Sanctum's own memory: built in, nothing to install. It recalls the closest lines from earlier conversations on this
   computer, and stands in for Revien whenever Revien is not running.
Which one? [4] 
Browser: a tenant has browser tools only from a seat of its own. Set integrations.browser_url in this tenant's tenant.yaml to use one; the process's seat is never shared.
